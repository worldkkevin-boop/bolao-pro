# Step 03 — Aprovar Pesquisa (Checkpoint)

## Tipo
Checkpoint — aguarda aprovação do usuário sobre os resultados da pesquisa.

## Objetivo
Apresentar os resultados da pesquisa de tendências do Pesquisador Pedro para validação do usuário antes de avançar para a criação do calendário editorial.

## Mensagem para o Usuário

```
🔍 Pesquisa de Tendências Concluída!

O Pesquisador Pedro finalizou a análise de tendências e mercado para o lançamento.

**Resumo dos achados:**
[Inserir resumo executivo do relatório de pesquisa]

**Principais recomendações:**
[Inserir top 3 recomendações priorizadas]

---

📋 **Para revisar:**
- O relatório completo está disponível acima
- Verifique se os insights estão alinhados com sua visão do lançamento
- Confirme se as hashtags e ângulos recomendados fazem sentido

**Opções:**
✅ **Aprovar** — Prosseguir para criação do calendário editorial
✏️ **Ajustar** — Solicitar mudanças ou aprofundamento em algum ponto
❌ **Refazer** — Pedir nova pesquisa com foco diferente
```

## Dados Esperados
- Relatório de pesquisa do Step 02
- Feedback do usuário (aprovação, ajustes ou refação)

## Próximo Passo
- Se aprovado → Step 04 (Criação do Calendário Editorial com Estrategista Estela)
- Se ajustes → Retornar ao Step 02 com feedback específico
