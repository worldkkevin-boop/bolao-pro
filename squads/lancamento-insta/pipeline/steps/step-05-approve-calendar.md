# Step 05 — Aprovar Calendário (Checkpoint)

## Tipo
Checkpoint — aguarda aprovação do usuário sobre o calendário editorial.

## Objetivo
Apresentar o calendário editorial de 7 posts criado pela Estrategista Estela para validação antes de iniciar a produção de copies.

## Mensagem para o Usuário

```
🧠 Calendário Editorial Concluído!

A Estrategista Estela finalizou o calendário de lançamento com 7 posts.

**Arco Narrativo:**
[Inserir arco narrativo resumido]

**Visão Geral dos Posts:**
[Inserir tabela-resumo do calendário]

---

📋 **Para revisar:**
- Verifique se a progressão narrativa faz sentido para seu lançamento
- Confirme se os formatos escolhidos são adequados
- Valide se as features do Bolão Pro que você quer destacar estão contempladas
- Cheque se os CTAs e métricas-alvo estão alinhados com seus objetivos

**Opções:**
✅ **Aprovar** — Prosseguir para produção de copies com a Redatora Rita
✏️ **Ajustar** — Solicitar mudanças em posts específicos (temas, formatos, ordem)
🔄 **Trocar posts** — Substituir um tema por outro
❌ **Refazer** — Pedir novo calendário com estrutura diferente
```

## Dados Esperados
- Calendário editorial completo do Step 04
- Feedback do usuário (aprovação, ajustes ou refação)

## Próximo Passo
- Se aprovado → Step 06 (Produção de Copies com Redatora Rita)
- Se ajustes → Retornar ao Step 04 com feedback específico
