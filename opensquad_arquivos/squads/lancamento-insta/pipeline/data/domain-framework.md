# Framework de Criação de Conteúdo — Pipeline de Lançamento Instagram

## Visão Geral do Pipeline

O pipeline de criação de conteúdo para lançamento no Instagram segue uma estrutura sequencial com checkpoints de validação. Cada etapa tem um propósito claro e gera um output específico que alimenta a próxima.

```
Briefing → Pesquisa → [Aprovação] → Calendário → [Aprovação] → Copies → Revisão → [Aprovação Final]
```

## Princípios do Framework

### 1. Research-First (Pesquisa Primeiro)
Nunca comece a produzir conteúdo sem pesquisa fundamentada. As tendências e insights do mercado devem direcionar toda a estratégia — não o contrário.

### 2. Strategy Before Execution (Estratégia Antes da Execução)
O calendário editorial define a estrutura narrativa antes de qualquer copy ser escrita. Isso garante coerência e progressão no conjunto dos posts.

### 3. Checkpoint Validation (Validação por Checkpoints)
O usuário valida o output de cada fase crítica antes de avançar. Isso evita retrabalho e garante alinhamento com a visão do lançamento.

### 4. Quality Gate (Gate de Qualidade)
A revisão é uma etapa obrigatória antes da entrega final. A Revisora funciona como quality gate com poder de veto e reenvio para reescrita.

### 5. Brand Consistency (Consistência de Marca)
Todas as etapas são ancoradas na identidade do Bolão Pro — tom "O Mago", estética dark/neon green, features específicas do produto.

## Fluxo de Dados Entre Etapas

### Step 01 → Step 02 (Briefing → Pesquisa)
- **Input**: Tópico/ângulo do lançamento, data, features prioritárias
- **Output**: Briefing de pesquisa direcionado

### Step 02 → Step 04 (Pesquisa → Calendário)
- **Input**: Relatório de tendências, análise competitiva, oportunidades
- **Output**: Insights priorizados para estruturar narrativa

### Step 04 → Step 06 (Calendário → Copies)
- **Input**: Calendário com 7 posts (tema, formato, tom, CTA, visual)
- **Output**: Briefing detalhado por post para produção de copy

### Step 06 → Step 07 (Copies → Revisão)
- **Input**: Copies completas (slides/roteiros, legendas, hashtags, briefings visuais)
- **Output**: Material para avaliação de qualidade

### Step 07 → Step 06 (Revisão → Copies) [em caso de rejeição]
- **Input**: Feedback classificado (🔴🟡🟢) com sugestões de melhoria
- **Output**: Direcionamento para reescrita

## Formato de Conteúdo: Instagram Feed

### Especificações por Formato

#### Reels
- **Duração recomendada**: 15-30 segundos
- **Proporção**: 9:16 (vertical)
- **Hook**: Primeiros 2 segundos — texto ou visual impactante
- **Texto sobreposto**: Essencial — 80% do público assiste sem som
- **Áudio**: Trilha trending ou original alinhada ao mood
- **CTA**: Último frame ou legenda

#### Carrosséis
- **Slides**: 7-10 slides (máximo alcance)
- **Proporção**: 1:1 (quadrado) ou 4:5 (retrato)
- **Slide 1**: Hook visual — funciona como thumbnail
- **Slides intermediários**: 1 ideia por slide, máximo 15 palavras
- **Último slide**: CTA claro (Salve, Compartilhe, Link na bio)
- **Design**: Consistente entre slides, com identidade visual forte

#### Posts Estáticos
- **Proporção**: 1:1 ou 4:5
- **Texto na arte**: Conciso, alto contraste com o fundo
- **Legenda**: Mais longa e narrativa (200-300 palavras)
- **Uso**: Marcos, anúncios oficiais, statements

### Estrutura de Legenda Padrão

```
[Hook — primeira frase que aparece antes do "...mais"]

[Corpo — contexto, storytelling, informação]

[CTA — ação desejada]

[Hashtags — 8-15, mix de volume e nicho]
```

## Critérios de Progressão Narrativa

### Modelo de Arco de Lançamento (7 Posts)

| Fase | Tom | Objetivo | CTA Type |
|------|-----|----------|----------|
| Teaser | Mistério, curiosidade | Gerar buzz | Awareness |
| Revelação | Excitação, surpresa | Apresentar o produto | Interesse |
| Educação | Didático, empolgante | Explicar como funciona | Consideração |
| Feature 1 | Competitivo, energético | Destacar diferencial | Engajamento |
| Feature 2 | Empolgante, exclusivo | Aprofundar valor | Desejo |
| Prova Social | Confiança, credibilidade | Validar decisão | Intenção |
| Conversão | Urgência, celebração | Converter em download | Ação |

## Glossário

- **Hook**: Elemento inicial (visual ou textual) que captura atenção
- **CTA**: Call to Action — chamada para ação específica
- **Briefing Visual**: Descrição detalhada para produção/geração de arte
- **Arco Narrativo**: Progressão emocional ao longo de múltiplos posts
- **Gate de Qualidade**: Ponto de verificação que pode bloquear avanço
- **Checkpoint**: Momento de validação com o usuário
- **PWA**: Progressive Web App — app que roda no navegador
