# Step 01 — Foco da Pesquisa (Checkpoint)

## Tipo
Checkpoint — aguarda input do usuário antes de prosseguir.

## Objetivo
Coletar do usuário o tópico/ângulo do lançamento para direcionar toda a pesquisa e produção de conteúdo.

## Mensagem para o Usuário

```
🚀 Lançamento Instagram — Bolão Pro

Antes de começar a produzir o conteúdo de lançamento, preciso entender o foco:

**Qual é o tópico/ângulo do lançamento?**

Exemplos:
- "Lançamento do app para o Brasileirão 2026"
- "Campanha de pré-lançamento — teaser misterioso"
- "Lançamento focado na feature de Tesouraria"
- "Campanha para Copa do Brasil 2026"

**Informações adicionais úteis (opcionais):**
- Data prevista de lançamento do app
- Alguma feature específica para destacar?
- Existe algum evento/campeonato próximo para aproveitar?
- Tom preferido (mais misterioso ou mais direto)?

Por favor, descreva o foco do lançamento para que o squad possa começar a trabalhar! 🪄
```

## Dados Coletados
- Tópico/ângulo principal do lançamento
- Data prevista (se fornecida)
- Features prioritárias (se informadas)
- Contexto de campeonato/evento (se informado)
- Preferências de tom (se informadas)
