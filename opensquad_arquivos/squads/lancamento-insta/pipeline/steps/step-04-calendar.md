# Step 04 — Calendário Editorial

## Configuração
- **Agente**: Estrategista Estela (strategist)
- **Execução**: inline

## Context Loading

Carregue os seguintes dados antes de executar:
- Output do Step 02 — Relatório de pesquisa aprovado pelo usuário
- Input original do usuário do Step 01 (tópico/ângulo do lançamento)
- `pipeline/data/domain-framework.md` — framework do pipeline de conteúdo
- `pipeline/data/quality-criteria.md` — critérios de qualidade para conteúdo Instagram
- `pipeline/data/tone-of-voice.md` — tom de voz do Bolão Pro

## Instruções

### Processo

1. **Absorva os insights da pesquisa**: Extraia do relatório do Pesquisador Pedro os insights mais relevantes para montar a narrativa de lançamento:
   - Formatos que performam melhor (Reels, carrosséis, estáticos)
   - Ângulos e oportunidades identificadas
   - Hashtags recomendadas
   - Timing e sazonalidade

2. **Defina o arco narrativo dos 7 posts**: Estabeleça a jornada emocional do público ao longo dos 7 posts. O arco padrão é:
   - D1: Mistério/Teaser → D2: Revelação → D3: Educação → D4: Feature destaque → D5: Feature complementar → D6: Prova Social → D7: Urgência/Conversão
   - Adapte conforme o tópico específico do lançamento

3. **Distribua os formatos estrategicamente**: Aloque formatos diferentes para cada dia, garantindo variedade:
   - Mínimo 2 Reels, 2 carrosséis e 1 post estático nos 7 posts
   - Nunca repetir o mesmo formato em dias consecutivos
   - Considerar o melhor formato para cada tema/objetivo

4. **Detalhe cada post**: Para cada um dos 7 posts, defina:
   - Tema específico conectado a uma feature ou ângulo do Bolão Pro
   - Formato (Reel, carrossel, post estático)
   - Tom emocional predominante
   - CTA progressivo (de curiosidade a conversão)
   - Métrica-alvo (alcance, saves, shares, cliques, downloads)
   - Direção visual com referência às cores e ao tema "O Mago"

5. **Monte a tabela-resumo**: Compile todos os posts em uma tabela visual com: Dia, Tema, Formato, Tom, CTA e Objetivo.

6. **Valide a coerência**: Revise o calendário como um todo:
   - A progressão narrativa faz sentido?
   - Os CTAs evoluem gradualmente?
   - Todas as features principais estão cobertas?
   - A diversidade de formatos está adequada?

## Veto Conditions

1. **Sem progressão narrativa**: Se os 7 posts parecem aleatórios e não contam uma história coerente de lançamento, o calendário precisa ser reestruturado.

2. **Formatos repetitivos**: Se mais de 2 posts consecutivos usam o mesmo formato, o calendário não tem diversidade suficiente para maximizar alcance.

3. **Features não cobertas**: Se alguma das 5 features principais (7 regras, Tesouraria, Perguntas Bônus, PWA, rankings) não aparece em nenhum post, o calendário está incompleto.

## Quality Criteria
- [ ] Calendário tem exatamente 7 posts
- [ ] Progressão narrativa clara (mistério → revelação → educação → conversão)
- [ ] Pelo menos 3 formatos diferentes usados
- [ ] Sem formatos repetidos em dias consecutivos
- [ ] Cada post tem: tema, formato, tom, CTA, direção visual e métrica-alvo
- [ ] Todas as 5 features principais do Bolão Pro cobertas
- [ ] CTAs evoluem progressivamente
- [ ] Briefings visuais referenciam cores da marca (#09090b, #10b981)
- [ ] Tabela-resumo completa e legível
