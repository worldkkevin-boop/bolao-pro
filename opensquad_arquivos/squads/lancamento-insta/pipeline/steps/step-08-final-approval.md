# Step 08 — Aprovação Final (Checkpoint)

## Tipo
Checkpoint — aprovação final do usuário antes da entrega do conteúdo.

## Objetivo
Apresentar todo o conteúdo de lançamento revisado e aprovado pela Revisora Renata para aprovação final do usuário. Este é o último gate antes da entrega dos arquivos finais.

## Mensagem para o Usuário

```
🚀 Conteúdo de Lançamento Pronto para Aprovação Final!

Todo o conteúdo passou pelo pipeline completo:
✅ Pesquisa de tendências (Pesquisador Pedro)
✅ Calendário editorial (Estrategista Estela)
✅ Produção de copies (Redatora Rita)
✅ Revisão de qualidade (Revisora Renata)

**Resumo do que foi produzido:**
- 📅 Calendário com 7 posts de lançamento
- ✍️ Copy completa para cada post (slides/roteiros + legendas + hashtags)
- 🎨 Briefings visuais detalhados para geração de imagem
- 📊 Métricas-alvo por post

**Status da Revisão:**
[Inserir status da Revisora Renata e resumo do feedback]

---

📋 **Para revisar:**
- Leia os copies e legendas de cada post
- Verifique se o tom está alinhado com sua visão do Bolão Pro
- Confirme se os briefings visuais são adequados
- Valide os CTAs e hashtags

**Opções:**
✅ **Aprovar e Entregar** — Gerar os arquivos finais na pasta /output
✏️ **Ajustes pontuais** — Solicitar pequenas mudanças em posts específicos
🔄 **Revisão adicional** — Enviar de volta para a Redatora Rita
❌ **Recomeçar etapa** — Refazer a produção de copies com novo direcionamento
```

## Dados Esperados
- Conteúdo completo do Step 06 (copies)
- Relatório de revisão do Step 07
- Feedback final do usuário

## Entrega Final
Após aprovação, os arquivos finais são salvos em:
- `output/calendario-editorial.md` — Calendário resumo
- `output/copies-completas.md` — Todas as copies e legendas
- `output/briefings-visuais.md` — Todos os briefings para geração de imagem
- `output/hashtags-master.md` — Lista consolidada de hashtags

## Próximo Passo
- Se aprovado → Gerar arquivos finais em /output e encerrar pipeline
- Se ajustes → Aplicar ajustes e retornar para aprovação
- Se revisão → Retornar ao Step 06 com feedback
